Generador de video con Wan3.0

Escribe una descripción y Alibaba Cloud Model Studio genera el video. Toma entre 1 y 5 minutos.

Esta página no se abre con doble clic. Necesita el programa local: ejecuta iniciar.bat (Windows) o python3 servidor.py (Mac/Linux) y usa la dirección http://127.0.0.1:8000 que se abre sola en el navegador.

1. Tu cuenta de Model Studio

La API key, el workspace y el modelo deben ser de la misma región y el modelo debe estar activado en la consola; si no, la llamada falla.

Tu API key no se guarda: se envía cifrada (HTTPS) a este servidor solo para reenviarla a Alibaba y no queda registrada.

2. Imágenes de referencia (opcional)

Haz clic o arrastra imágenes aquí (hasta 5): logos, productos o la foto de una persona

Las imágenes se envían directo a Alibaba para generar el video; este servidor no las guarda. Los logos con fondo transparente se pasan a fondo blanco. Wan usa las imágenes como referencia: el parecido y los textos de un logo no están garantizados al 100 %.

3. El video

Se desactiva cuando hay texto hablado para que Alibaba no lo reescriba.

Ver el prompt final que se enviará

Cada generación consume saldo de tu cuenta. Para probar, usa 480P y 5 segundos.
